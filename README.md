# concert-management-database-sql

A relational database project designed to manage concerts, artists, venues, ticket sales, and customer bookings using SQL.

# Project Overview

This project focuses on designing and implementing a normalized relational database for a concert management system.
It supports storing, managing, and analyzing concert-related data such as events, artists, venues, and ticket sales.

The project demonstrates strong skills in:

Database schema design

Data modeling

SQL querying

Analytical reporting
